# 后续部署方案

本次仅搭建骨架，没有修改任何现有服务器或站点，也没有复用诗词数据。

建议在已确认的HTTPS域名下使用独立路径，例如 /citywalk/catalog.json。
生产数据只能来自npm run data:release生成的dist/catalog.json。
草案不能上传为正式攻略；如果演示确需联网草案，必须使用不同路径并在UI显示草案状态。

成员6准备JSON更新模块和部署操作说明，成员1审核后执行部署。
不需要新建数据库、开放额外端口或购买实时数据服务。
客户端需配置request合法域名，真机验证由实际小程序管理员配合完成。

更新策略验收：响应状态→根版本→记录结构→唯一ID→引用→耗时→缓存写入→替换内存数据。
任一步失败保留原数据；未支持的schemaVersion提示升级客户端。
