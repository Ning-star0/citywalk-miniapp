# 骨架验收与后续集成

## 本次骨架检查

- XML通过XSD及业务校验，JSON/JS生成物与XML一致。
- 坏数据无法绕过：重复ID、错误引用、负耗时、顺序错误、超范围坐标、verified缺来源。
- 发布命令对draft返回非零退出码，不生成正式发布文件。
- 公共服务支持关键词、商圈、地铁和耗时组合筛选。
- 未找到路线返回null，页面展示空状态。
- 本地收藏保存失败不得提示收藏成功。

## 团队完整交付前

- 至少6条真实贵阳路线完成来源审校，距离与耗时标注为估算。
- 每条至少2个点位，地铁站名称和入口方向经过核验。
- 地图仅对verified且有GCJ-02坐标的点位开放，失败时给出提示。
- 收藏和打卡重启后可恢复，写入失败可见，不能静默抹除用户数据。
- 网络错误、无效JSON、不支持的schemaVersion均保留最后有效数据。
- 有网、断网、空搜索、非法详情ID、不同屏幕均进行实际微信工具测试。
- 最后用真实AppID做真机预览，正式发布另走微信要求的流程。
- 团队介绍填写真实成员与实际贡献，保存Issue/PR与测试证据。

首页 → 搜索 → 按商圈/地铁/耗时筛选 → 路线详情与时间拆分 → 地图 → 收藏 → 打卡 → 更新失败回退。
